# UI Kit — Last Place studio website

An interactive click-through recreation of the Last Place studio site, built
from the brand's visual foundations and composed from the design-system
components (`Button`, `TextLink`, `Tag`, `Card`, `Field`, `Checkbox`).

Open `index.html`. The header navigates between four surfaces:

- **Home** (`HomeScreen.jsx`) — hero with the plant mark, lede, and a selected-works grid.
- **Work** (`WorkScreen.jsx`) — an editorial project index; rows reveal blue and shift right on hover.
- **Studio** (`StudioScreen.jsx`) — the about page with a services grid.
- **Contact** (`ContactScreen.jsx`) — a working (fake) enquiry form with budget chips and a sent state.

Shared chrome: `Header.jsx`, `Footer.jsx`. Fake content: `projects.js`.

All copy and imagery follow the brand: hyperlink blue, Cormorant, mono labels,
hairline rules, and the blue lino-print plant. Project thumbnails are solid
blue / ink / paper wells with serif initials — placeholders standing in for the
studio's real case-study imagery.
