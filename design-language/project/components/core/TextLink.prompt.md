The signature hyperlink-blue inline link — underlined, the underline lifts away on hover.

```jsx
<p>See our <TextLink href="/work">selected work</TextLink>.</p>
<TextLink href="/project" arrow>View project</TextLink>
```

Props: `href`, `arrow` (prefix the brand ↳), `muted` (ink instead of blue, for use inside already-blue surfaces).
