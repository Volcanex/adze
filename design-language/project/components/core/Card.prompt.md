A restrained project / work card — hairline border, square corners, an optional media well that defaults to brand blue. Hovering a linked card lifts the border to ink and gently scales the image.

```jsx
<Card
  href="/work/onwards"
  eyebrow="Branding · Web"
  title="Onwards Norfolk"
  meta="2025 — Norfolk BIDs"
  media="/assets/work-onwards.jpg"
>
  An events platform for the Bradford district.
</Card>
```

Props: `eyebrow`, `title`, `meta`, `media` (src or node), `mediaBg`, `href`, plus body via `children`.
