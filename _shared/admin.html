Frozen snapshot of the original look — Cardo serif italic headings, 8px radius. Kept for reference now that the chrome has moved to mono. Static on purpose, so it always shows the legacy style.

Alt 2 — Mono / Technical now live

Most mono of the set. Wordmark, headings and labels in JetBrains Mono; Inter for body. Tracked uppercase, 4px radius, hairline rules — reads like a clean engineering doc. Same colour tokens as canon.

Open example 2
Alt 3 — Clean Sans / Swiss

One typeface (Inter) doing everything via weight — 800 display, 300 body. No serif, mono reserved for code, near-square 2px radius, generous whitespace. The most neutral, contemporary feel.

Open example 3
Alt 4 — Editorial (upright serif)

The middle ground: keeps a serif for warmth but upright (never italic) on the sharper Fraunces instead of Cardo. Kills the cursive read while staying closest to today's identity — the smallest jump.
